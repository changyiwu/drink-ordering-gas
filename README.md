# drink-ordering-gas 🥤 飲料線上訂購系統 (GAS 版本)

本專案是配合 Google Sheets (試算表) 與 Google Apps Script (GAS) 建立的飲料線上訂購系統。

## 特色

- **即時試算表儲存**：填單後自動寫入關聯的 Google 試算表。
- **即時訂單看板**：讀取試算表中的所有訂單，展示最新點餐情形。
- **響應式網頁設計**：針對手機與社群軟體 (LINE、FB、IG) 的內置瀏覽器進行高度優化。

## 目錄結構

- `Code.gs`：Google Apps Script 後端程式碼。
- `Index.html`：RWD 前端網頁（CSS/JS 整合於此檔案中）。
